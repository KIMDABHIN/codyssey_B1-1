LLM 모델 비교·선정 보고서
1. 비교 목적
1.1 비교 목적
본 보고서는 AI 기반 맞춤형 여행 일정 설계 시스템 구축에 적합한 대규모 언어 모델(LLM)을 선정하기 위해 작성하였다. 동일한 여행 일정 생성 과업을 Gemini 3.1 Flash Lite, Claude Haiku 4.5, GPT-5 Mini에 동일한 프롬프트로 수행하도록 한 후, 결과를 비교·분석하였다.
평가 항목은 조건 반영의 정확성, 한국어 자연스러움, 긴 문맥 유지 능력, 출력 형식 준수, 응답 속도 및 안정성, 비용 효율성, 도구 연동 적합성으로 구성하였으며, 이를 바탕으로 여행 일정 설계 AI에 가장 적합한 모델을 선정하였다.
2. 비교 대상 모델
| 모델                    | 특징                              |
| --------------------- | ------------------------------- |
| Gemini 3.1 Flash Lite | 빠른 응답 속도와 비용 효율성이 높은 경량 모델      |
| Claude Haiku 4.5      | 긴 문맥 유지와 자연스러운 문장 생성에 강점이 있는 모델 |
| GPT-5 Mini            | 구조화된 출력과 다양한 도구 활용에 강점을 가진 모델   |
3. 동일 테스트 프롬프트
부산 2박 3일 여행 일정을 작성해줘.
조건은 다음과 같다.
- 예산 50만 원
- 대중교통 이용
- 친구 2명과 여행
- 해산물 제외
- 카페 2곳 포함
- 바다를 볼 수 있는 장소 포함
- 이동 동선을 고려하여 일정 작성
- 예상 비용을 표로 정리
- 마지막에 여행 준비물 체크리스트도 작성
