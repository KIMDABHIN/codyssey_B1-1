#LLM 모델 비교·선정 보고서

# 1. 비교 목적
## 1.1 비교 목적
본 보고서는 AI 기반 맞춤형 여행 일정 설계 시스템 구축에 적합한 대규모 언어 모델(LLM)을 선정하기 위해 작성하였다. 동일한 여행 일정 생성 과업을 Gemini 3.1 Flash Lite, Claude Haiku 4.5, GPT-5 Mini에 동일한 프롬프트로 수행하도록 한 후, 결과를 비교·분석하였다.
평가 항목은 조건 반영의 정확성, 한국어 자연스러움, 긴 문맥 유지 능력, 출력 형식 준수, 응답 속도 및 안정성, 비용 효율성, 도구 연동 적합성으로 구성하였으며, 이를 바탕으로 여행 일정 설계 AI에 가장 적합한 모델을 선정하였다.

# 2. 비교 대상 모델
| 모델 | 특징 |
|------|------|
| Gemini 3.1 Flash Lite | 빠른 응답 속도와 비용 효율성이 높은 경량 모델 |
| Claude Haiku 4.5 | 긴 문맥 유지와 자연스러운 문장 생성에 강점이 있는 모델 |
| GPT-5 Mini | 구조화된 출력과 다양한 도구 활용에 강점을 가진 모델 |

# 3. 동일 테스트 프롬프트
부산으로 2박 3일 여행 일정을 작성해줘.
조건은 다음과 같다.
-예산 50만원
-대중교통 이용
-친구 2명과 여행
-해산물 제외
-카페 2곳 포함
-바다를 볼 수 있는 장소 포함
-이동 동선을 고려하여 일정 작성
-예상 비용을 표로 정리
-모델별 결과 요약마지막에 여행 준비물 체크리스트도 작성

# 4.평가 기준
  | 평가 기준 | 평가 내용 |
|-----------|-----------|
| 정확성 | 사용자가 제시한 조건을 빠짐없이 반영했는가 |
| 한국어 자연스러움 | 문장이 자연스럽고 이해하기 쉬운가 |
| 긴 문맥 유지 | 여러 조건을 일관성 있게 유지하는가 |
| 형식 준수 | 일정표, 비용표, 체크리스트 등 요구한 형식을 준수하는가 |
| 속도 및 안정성 | 응답 속도가 빠르고 안정적인가 |
| 비용 | 사용 비용 및 토큰 효율성이 적절한가 |
| 도구 연동 적합성 | 여행 일정 자동화 시스템과 연동하기 적합한가 |

# 7.모델별 결과 비교표와 최종 선정 결론
## 7-1 모델별 결과 비교표
| 모델                    | 강점                                                 | 약점                                 |
| --------------------- | -------------------------------------------------- | ---------------------------------- |
| Gemini 3.1 Flash Lite | 실제 맛집·카페 정보와 여행 팁이 풍부하며 실용적인 여행 정보를 많이 제공함         | 답변 분량이 길고 일부 구조화된 출력 형식이 부족함       |
| Claude Haiku 4.5      | 시간표 형식과 동선 설명이 체계적이며 가독성이 높음. 예산 관리와 문맥 유지 능력이 우수함 | 카페명, 맛집 등 구체적인 장소 정보가 상대적으로 부족함    |
| GPT-5 Mini            | 요구 조건을 명확히 반영하고 일정·동선·비용·체크리스트 구성이 균형 잡힘           | 실제 장소에 대한 구체적인 추천 정보는 Gemini보다 부족함 |

## 7-2 최종 선정 결론
세 모델 모두 기본 요구사항을 충족했지만, 본 과제의 목표인 “조건이 많은 여행 일정 설계 업무를 안정적으로 수행하는 AI” 관점에서 Claude Haiku 4.5를 최종 선정하였다.
선정 이유
-동선 최적화 설명이 가장 명확하여 실제 이동 계획을 이해하기 쉬웠다.
-시간표 형식의 구조화된 출력으로 보고서와 시스템 연동에 유리했다.
-예산, 일정, 체크리스트 등 여러 조건을 끝까지 일관되게 유지하였다.
